# AutoMark

本地优先的试卷组卷与答题卡批改工具 —— 面向教师个人使用（Windows）。

一键完成 **组卷 → 打印 → 扫描 → 自动批改 → 成绩导出** 的完整闭环。所有数据保存在本机，无需联网。

## 下载与安装

👉 **下载安装包**：[Releases 页面](https://github.com/whoisjimmywong/automark/releases)（下载 `AutoMark Setup x.x.x.exe`）

- **系统要求**：Windows 10 / 11（64 位），无需安装 Python、Node 等任何环境
- **安装**：双击安装包 → 选择安装目录 → 完成；桌面会生成「AutoMark」快捷方式
- **启动**：双击「AutoMark」即可，自动拉起全部服务并打开主界面
- **卸载**：开始菜单或安装目录中的卸载程序

> 💡 首次运行若杀毒软件提示，请选择「保留 / 允许运行」（安装包与内置识别程序未做代码签名，属常见误报）。

## 功能特性

- **组卷**：可视化编辑器（富文本题干、选项拖拽排序、多空填空逐空赋分、完形/阅读文章），或直接导入 AMF 格式；一键生成 PDF 三件套：**试卷 / 答题卡 / 答案卷**。
- **答题卡**：双栏布局、二维码页码、四角定位标记；学号涂卡区、缺考/异常标记圈；选项排列支持单排/双排/双列/竖排。
- **自动批改**：扫描件上传（PDF/图片）→ 自动配准 → 涂卡识别（自适应阈值，铅笔深浅都能读）→ 学号自动读取 → 客观题判分（单选/多选/判断，含部分分）。
- **填空识别**：本地 OCR 多路径识别；识别不清时可调用 LLM 视觉 API 复核（可在设置中关闭）；识别歧义自动进入人工复核队列，看原图裁剪一键确认。
- **人工批改模式**：选择题自动批改，填空题由教师逐空人工判定（作答切图 + 参考答案，对/错/空白）。
- **成绩导出**：一键导出 XLSX（元数据 / 逐题作答 / 学生成绩 / 班级统计）。

## 使用流程

1. **组卷**：新建项目 → 编辑题目与标准答案 → 生成并打印三件套。
2. **作答**：学生直接在试卷/答题卡上作答（选择题涂卡，填空题手写）。
3. **扫描**：回收后用扫描仪/手机扫描或拍照，上传 PDF 或图片（每份文件 = 一名学生）。
4. **批改**：点击「开始批改」（可选「填空人工批改」模式）；有复核项时进入复核/人工批改处理。
5. **导出**：生成 XLSX 成绩单。

## 数据与隐私

- 所有数据（组卷、扫描件、批改结果、设置）**仅保存在本机**，不上传任何云端
- 安装版数据目录：`%APPDATA%\AutoMark`（删除即清除全部数据）
- 使用 LLM 复核功能时，仅将"填空作答框截图"发送至你配置的 API 服务（默认关闭）

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 杀毒软件报警 | 未签名程序常见误报，选择「保留/允许」即可 |
| 端口被占用 | 服务使用 8790/8791 本地端口，极少冲突；冲突时先关闭占用程序 |
| 识别不准 | 确保扫描端正、光线均匀；低置信项会进入复核，人工确认即可 |
| 如何导入已有试卷 | 组卷页 → 导入 AMF 文件（格式见 examples 目录） |
