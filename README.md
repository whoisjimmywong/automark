# AutoMark

本地优先的试卷组卷与答题卡批改工具 —— 面向教师个人使用（Windows）。

一键完成 **组卷 → 打印 → 扫描 → 自动批改 → 成绩导出** 的完整闭环，所有数据保存在本机，无需联网。

## 功能特性

- **组卷（AMF）**：可视化编辑器（富文本题干、选项拖拽排序、多空填空逐空赋分、阅读 passage 结构化），或直接导入 AMF JSON；一键生成 PDF 三件套：**试卷 / 答题卡 / 答案卷**。
- **答题卡设计**：列主序双栏布局（先左列再右列，避免左右横跳）、二维码页码、四角定位标记；学号涂卡区、缺考/异常标记圈；选项排列支持单排/双排/双列/竖排；长阅读文章自动跨页。
- **自动批改**：扫描件上传（PDF/图片）→ 透视矫正配准 → 涂卡识别（自适应阈值，抗铅笔浅涂与扫描亮度差异）→ 学号自动读取 → 客观题判分（单选/多选/判断，支持部分分与容差）。
- **填空识别**：RapidOCR 多路径识别（检测/整框识别/自适应裁边），低置信或无法识别时自动调用 **LLM 视觉 API 复核**（可关闭）；识别歧义进入人工复核队列，裁剪原图核对、一键采纳备选答案。
- **人工批改模式**：选择题自动批改 + 填空题**逐空人工批改**（作答切图 + 参考答案，对/错/空白）。
- **成绩导出**：XLSX 四工作表（元数据 / 逐题作答 / 学生成绩 / 班级统计）。

## 架构

三进程本地架构（数据不出本机）：

| 服务 | 技术栈 | 职责 |
| --- | --- | --- |
| web | React 18 + Vite | 前端：组卷编辑器 / 批改 / 复核 / 设置 |
| server | Node.js + TypeScript + Fastify | 项目与 AMF 管理、判分引擎、导出 |
| vision | Python + FastAPI + OpenCV + RapidOCR | 布局引擎（PDF 生成）、扫描配准、涂卡识别、填空 OCR |

## 快速开始

要求：Node ≥ 20、pnpm、Python 3.11+（首次启动自动创建 `vision/.venv` 并安装依赖）

- **双击启动（Windows）**：运行根目录 **`AutoMark.bat`**（自动检查依赖、拉起三个服务并打开应用窗口，关闭窗口最小化到托盘）。
- **命令行方式**：

```bash
pnpm install
pnpm dev
```

浏览器打开 http://127.0.0.1:5173 即可使用。可导入 [`examples/amf_english_unit3.json`](examples/amf_english_unit3.json)（含 5 种题型示例）快速体验。

## 使用流程

1. **组卷**：新建项目或导入 AMF → 编辑题目与答案 → 生成三件套 PDF 并打印。
2. **作答**：学生直接在试卷/答题卡上作答（选择题涂卡，填空题手写）。
3. **扫描**：回收后扫描或拍照上传（每份文件 = 一名学生）。
4. **批改**：选择「自动批改」或「填空人工批改」模式 → 处理复核项 / 逐空人工批改。
5. **导出**：生成 XLSX 成绩单。
